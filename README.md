# DeepSeek Chat Demo — 长对话修复版

纯网页版，不需要安装 App。用 Safari 或任意现代浏览器打开 `index.html` 即可。

## 使用方法

1. 打开网页，在设置里输入 DeepSeek API Key。
2. 原先导出的历史对话，可在「设置 → 数据管理 → 导入历史对话」中导入。
3. API Key 和历史记录只保存在当前浏览器本地，不会上传到其他服务器；对话请求直接发送给 DeepSeek API。

## 这一版修了什么

- 长会话首屏只渲染最近 24 条消息，避免手机浏览器因 DOM 和内存占用过大而崩溃。
- 顶部提供「加载更早的消息」，每次向前展开 24 条，并保持阅读位置。
- 继续聊天时只携带最近 12 轮、最多约 6 万字符的上下文，防止请求体无限增长。
- 原始历史记录不会被删除，只影响当前显示和提交给模型的范围。

## 请求一直“思考”怎么办

先打开同目录的 `doctor.html` 做一次最小请求诊断：它会读取当前页面保存的 Key，并显示连接、HTTP 状态、首字节、首个文本 token 的耗时。

- 401：Key 无效或已删除
- 429：额度/频率限制
- 200 但长时间无首字：DeepSeek 侧排队或网络中断
- 很快返回：问题在长上下文或前端请求

聊天页也加了看门狗：DeepSeek 连接或流式响应连续 75 秒没有任何数据时会主动中止，不会再无限等待。

## 部署成公开网页

把本目录全部文件上传到任意 HTTPS 静态托管即可，例如 GitHub Pages、Cloudflare Pages、Vercel。

不需要后端服务器。页面会从浏览器直接请求 `https://api.deepseek.com`。

## 注意

- 使用前请先从原版 demo 导出历史备份。
- 旧长对话被修复版接管后，只会默认显示最近 24 条；需要时可以点「加载更早的消息」。
- 「最近 12 轮 / 6 万字符」意味着更早的上下文不会发送给模型，模型不会记得那部分内容。
